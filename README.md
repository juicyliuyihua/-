# 模电学习手册 · 知识串讲修订版

本版依据《模拟电子技术基础》的十章目录补充知识讲解，纠正原先题型摘要与教材题号不对应的问题。

本仓库当前同步范围：
- 十章知识串讲与教材目录对照。
- 第二章Q点、直流/交流负载线、小信号分析、共集/共基及多级放大重点讲解。
- 场效应管工作区、频率响应、差分负载折算、运放与比较器、反馈量纲、功放、滤波振荡及稳压边界。
- 明确公式的单位、近似条件与适用电路。

**当前未包含教材习题及书后答案扫描页。** 整页教材图像公开发布需另行明确授权。原先不对应原题的练习摘要已移除，避免误认为教材完整原题或逐题详解。

直接用浏览器打开`index.html`即可阅读。本页不依赖外部图片或脚本。
