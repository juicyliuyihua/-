# 模拟电子技术学习手册

合并用户提供的两份 HTML 讲义，包含第 1—10 章知识摘要、五张重新绘制的 SVG 示意图和可展开的复习思路。

## 使用

下载 `index.html` 后可直接用浏览器打开，无外部依赖。支持章节目录、展开/收起、答案展开、打印为 PDF。小屏幕可在电路图区域横向滚动。

## 内容范围

这是复习讲义，不是教材全文或已逐题核对的标准答案。题目多为题型摘要，部分缺少原图或数值，不能当作完整作业题。已修正明显概念错误，但尚未完成与教材十章全部内容的逐条校对。
