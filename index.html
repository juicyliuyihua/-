1.1 半导体的基础知识

1.1.1 本征半导体

  • 纯净硅/锗晶体，依靠共价键结合；受热、光照发生本征激发，产生成对自由电子-空穴对。
  • 两种载流子参与导电：电子（负）、空穴（正）；金属导电通常用自由电子模型描述。
  • 载流子不断产生、复合，达到动态平衡；温度越高，载流子数量越多，导电能力越强。室温本征载流子浓度很低。

1.1.2 N型、P型杂质半导体

  • N型半导体（掺五价磷）：多子=自由电子；少子=空穴。
  • P型半导体（掺三价硼）：多子=空穴；少子=自由电子。
  • 重要结论：N/P半导体整体电中性；多子浓度由掺杂浓度决定；少子浓度主要受温度控制。

1.2 PN结的形成及特性

1.2.1 PN结形成

  • 同一块晶片一边做P区，一边N区；浓度差引发多子扩散运动；交界面留下不可移动正负离子，形成空间电荷区（耗尽层、内电场）。
  • 内电场阻碍扩散，推动少子漂移运动；无外加电压，扩散电流=漂移电流，动态平衡，形成PN结。

1.2.2 PN结单向导电性

  • 正向偏置：P接电源+，N接-：外电场抵消内电场，耗尽层变窄；扩散>>漂移，PN结导通，正向电流大。
  • 反向偏置：P接-，N接+：耗尽层变宽；只有微弱少子漂移，反向饱和电流IS很小，近似截止。
易错：PN结直接短路，金属接触电势抵消内建电势，不会产生持续电流。

1.3 半导体二极管

  • 二极管 = PN结 +引线外壳；P引出阳极，N引出阴极；分点接触、面接触、平面型。
  • 伏安特性：硅管死区电压约0.5V，导通压降0.6~0.8V；锗管死区约0.1V，导通压降0.2~0.3V；反向电压超过击穿电压发生反向击穿。
  • 主要参数：最大整流电流IF；最高反向工作电压UR；反向电流IR；极间电容Cd；反向恢复时间TRR。

1.4 二极管基本电路及分析方法

1.4.1 四种等效模型

  1. 理想模型：正向压降0V，反向电流0；适合电源电压远大于管压降。
  2. 恒压降模型：硅管导通固定0.7V，反向截止；按题目规定采用此近似。
  3. 折线模型：导通段用门槛电压与斜率电阻串联表示；斜率电阻与Q点小信号电阻不是同一概念。
  4. 小信号微变模型：仅Q点微小交流信号。
    rd = UT / ID ≈ 26mV / ID（ID用A，结果为Ω） （常温T=300K）
rd和静态直流ID强相关，直流电流越大微变电阻越小。

1.4.2 模型分析法解题步骤

  1. 断开二极管，分别求阳极、阴极电位，得到开路电压。
  2. 理想模型中V阳极 > V阴极可判断正向导通；恒压降模型还需检查规定压降，替换对应等效模型。
  3. V阳极 < V阴极：二极管截止，支路断开，I=0。
  4. 多二极管电路：假设状态、求解电路，再逐管核验电压与电流方向。

1.4.3 二极管典型应用

  • 开关逻辑电路；半波/桥式整流；单向/双向限幅；多管串联低压稳压。

1.5 特殊二极管

  • 稳压二极管（齐纳管）：正常工作在反向电击穿区，击穿可逆；电流必须限制IZ ~ IZM。
    参数：UZ稳定电压；IZ稳定电流；IZM最大稳定电流；动态电阻 rZ=ΔUZ/ΔIZ，rZ越小稳压越好；PZM=UZIZM。
  • LED发光二极管：正向导通发光；光电二极管：反向偏置，光照越强反向电流越大；变容二极管：反向电压改变结电容；肖特基二极管：开关速度高，正向压降低。

补齐理解：从载流子到电路计算

先分清“为什么能导电”和“怎样算电路”。半导体物理解释器件特性；真正做电路题时，要把器件换成适用的等效模型。

1.1～1.3 不要混淆的四组概念

  • 扩散由浓度差引起；漂移由电场引起。电子运动方向与其形成的电流方向相反。
  • 耗尽层主要是失去可移动多数载流子的区域，留下固定离子，并非完全没有电荷。
  • 正向压降随电流和温度改变，“硅管0.7V”只是恒压降近似；题目给0.6V就用0.6V。
  • 击穿电压是器件特性，允许反向工作电压是使用限值；稳压管也必须限流，击穿不等于可以承受任意功率。

1.4 多管电路的可靠算法

分别假设各管导通/截止。导通管替换为规定压降，截止管开路；列KCL/KVL求电压电流。最后检查：导通电流能否沿阳极→阴极流动？截止管的正向电压是否不足以导通？只要一项不满足，就修改假设。“电压最大的管先导通”只适合特定钳位结构，不能当通用规则。

画限幅输出时，先算每个导通门限，再把输入波形分段。两个反向串联的稳压管限幅时，一只反向击穿、另一只正向导通，限幅值通常为 UZ+UD，不能只写UZ。

1.5 稳压范围：同时看轻载和重载

IZ=(UI−UZ)/R−IL
重载、最低输入：IZ≥IZmin
轻载、最高输入：IZ≤IZmax，且 UZIZ≤PZmax

电流单位统一用A时，电压除电流得到Ω；用V和mA时，结果是kΩ。不要把“mA数值”直接代入以A为单位的公式。

2.1 BJT双极结型晶体管

  • 类型NPN、PNP；三个区域：发射区、基区、集电区；两个PN结：发射结、集电结；电极e发射极，b基极，c集电极。
  • 关键结构特点：基区很薄，掺杂浓度很低；发射区掺杂浓度高；集电区面积大；发射区-集电区不对称，不能互换使用。

BJT三种工作状态（NPN硅管）

  1. 放大状态：发射结正偏，集电结反偏；电位VC > VB > VE
    IE = IB + IC； IC ≈ β IB； IE ≈ (1+β) IB
    本质：小基极电流IB控制大集电极电流IC。
  2. 饱和状态：发射结正偏，集电结正偏；VB > VC；IC不再随IB成β倍增大；硅管饱和压降UCES≈0.3V。
  3. 截止状态：发射结未充分正向导通，集电结通常反偏；IB≈0，IC≈0。
PNP管全部电压极性反转；放大状态电位VE > VB > VC，UEB>0。

BJT主要参数

  • 直流β̄，交流β；α=β/(1+β)；ICBO集电结反向饱和电流；穿透电流 ICEO=(1+β)ICBO。
  • 极限参数：ICM最大集电极电流；PCM为最大允许耗散功率；静态管耗PC≈ICUCE；反向击穿电压要区分测试接法；通常U(BR)CBO大于U(BR)CEO，选用时按题给额定值检查。

阻容耦合共射放大电路示意图

2.2-2.3 共射放大电路；图解法、小信号模型分析法

静态工作点Q（直流通路：耦合电容全部开路）

IBQ = (VCC − UBEQ) / Rb
ICQ ≈ β IBQ
UCEQ = VCC − ICQ Rc
  • Q点过低IBQ太小：截止失真，输出电压顶部被削平。
  • Q点过高IBQ太大：饱和失真，输出电压底部被削平。
  • 输入幅度增大时先触及余量较小的一侧，继续增大可能出现双向削顶。

小信号模型动态分析（中频：电容近似短路，理想直流电源交流接地）

rbe ≈ 200Ω + (1+β) · 26mV / IEQ（IEQ用A，结果为Ω）
适用于发射极交流接地、忽略rce的共射电路：
Au = uo/ui = − β(Rc//RL) / rbe
Ri = Rb // rbe
Ro ≈ Rc
Au负号代表共射电路输出输入相位反相180°；小信号模型只计算交流变化分量，不能用来求静态直流Q点。

2.4 分压式射极偏置电路（稳定静态工作点）

以下分压近似需满足 Rb1∥Rb2 ≪ (β+1)Re。不满足时，先作戴维南等效：VBB=VCCRb2/(Rb1+Rb2)，RB=Rb1∥Rb2；假设放大区，IBQ=(VBB−UBEQ)/[RB+(β+1)Re]，算完检查工作区。

  • 满足I1 ≫ IBQ，基极电位近似由电阻分压得到，VBQ基本不受温度影响。
  • 发射极电阻Re引入直流负反馈抑制ICQ随温度升高；并联旁路电容Ce消除Re对交流信号衰减。
VBQ ≈ Rb2/(Rb1+Rb2) · VCC
IEQ = (VBQ − UBEQ) / Re
UCEQ ≈ VCC − IEQ(Rc+Re)

2.5 共集电极放大电路（射极跟随器）

  • 电压放大倍数Au≈+1，小于1；输入电阻很高，输出电阻很低；电压跟随，电流放大。
  • 典型用途：输入缓冲隔离、输出级驱动低阻负载。

2.6 共基极放大电路

  • 电压增益高，输出输入相位同相；输入电阻很小，输出电阻大；高频特性优异。

2.7 多级放大电路

  • 耦合方式：
    ①阻容耦合：隔直，各级静态Q相互独立，不能放大直流和缓慢变化信号；
    ②直接耦合：可以放大直流信号，存在零点漂移问题。
  • 总电压增益：Au = Au1·Au2·Au3…；总输入电阻等于第一级输入电阻；总输出电阻等于最后一级输出电阻。

第二章从零串起来：一张电路，分三次看

第一次看直流：没有输入信号时，管子站在哪个工作点？第二次看交流：输入变化一点，输出变化多少？第三次看极限：变化太大时，先碰到截止还是饱和？这三件事分别对应Q点、增益、最大不失真幅度。

2.1.2～2.1.3 电流放大与特性曲线

发射结正偏使载流子从发射区注入薄基区；少部分在基区复合，绝大部分到达集电结并被收集。因此 IC远大于IB。输入特性看固定UCE时iB随uBE怎样变；输出特性看固定iB时iC随uCE怎样变。一条输出曲线对应一个基极电流。

“放大”能量来自直流电源。输入信号控制电源向负载送能量；三极管本身不是能量源。交流β是Q点附近的斜率ΔiC/ΔiB，不必与直流比值完全相同。

2.2 电路各部分为什么存在

偏置电阻给基极提供直流通路；RC把集电极电流变化变成电压变化；VCC提供能量；耦合电容隔开前后级直流；RL是真正接收输出的负载。NPN共射输入升高→基极电流增大→集电极电流增大→RC压降增大→集电极电位降低，所以输出反相。

2.3.1 负载线：直流和交流为什么不同

对发射极接地、输出电容耦合的共射电路，直流时电容开路，RL不参与，负载线为 UCE=VCC−ICRC。它与偏置所对应的输出特性曲线相交，得到Q点。

中频交流时，输出电容近似短路，交流负载变为 R′=RC∥RL。交流负载线通过Q点，在“纵轴iC、横轴uCE”坐标中斜率为−1/R′，不能仍沿原来的直流线摆动。

发射极交流接地时：Uom,max≈min[ICQR′，UCEQ−UCE(sat)]
对应正弦有效值 Uo,max=Uom,max/√2

前一项是截止方向的余量，后一项是饱和方向的余量。有未旁路射极电阻时，要重新按电路求交流负载线及输出摆幅。

2.3.2 四个动态量，必须说清从哪里量

量定义常见漏项
Auuo/ui输出负载会使增益下降
Ausuo/us=AuRi/(Rs+Ri)信号源内阻的输入分压
Ri输入端ui/ii偏置电阻也是并联支路
Ro输入独立信号源置零、取下负载后，从输出端看进去保留Rs与受控源，不能直接把RL算进去

电压源置零等于短路，电流源置零等于开路。理想直流电源在交流等效中接地；理想恒流源在交流等效中开路。受控源始终保留。

2.4 射极电阻：稳定Q点，也可能减小交流增益

温度上升通常使电流增大→RE压降增大→UBE减小→抑制电流继续增大，这是直流负反馈。电容只旁路哪一段电阻，交流时就只消去哪一段，不能把所有射极电阻一并删掉。

令未旁路射极电阻为REu，忽略rce：
rin,b=rbe+(β+1)REu
Au=−β(RC∥RL)/[rbe+(β+1)REu]
Ri=RB1∥RB2∥rin,b

2.5～2.6 共集、共基不只需要记结论

“共”指输入和输出的公共交流端。共集从基极输入、发射极输出；共基从发射极输入、集电极输出。

共集：令 R′E=RE∥RL
Au=(β+1)R′E/[rbe+(β+1)R′E]
Ri=RB∥[rbe+(β+1)R′E]
Ro≈RE∥[(rbe+Rs∥RB)/(β+1)]
共基（基极交流接地）：rin,e≈rbe/(β+1)，Au≈+β(RC∥RL)/rbe

这些式子均忽略晶体管输出电阻；如果输入端另有射极偏置电阻，需要把它并入共基输入电阻。PNP先标清电压、电流方向，再列回路，别硬套NPN正电源公式。

2.7.1 共射—共基：高增益与较宽带宽

下管共射接收输入，上管共基把电流送到输出。上管发射极输入阻抗较小，使下管集电极电压变化较小，减弱下管集电结电容的密勒放大。这是共射—共基组合改善高频性能的原因；它不是简单把两级空载增益相乘。

2.7.2 共集—共集：复合管/达林顿连接

前管发射极电流成为后管基极电流。对于同极性达林顿管，总电流增益 β≈β₁β₂+β₁+β₂，常近似β₁β₂；两个发射结串联，导通需要约两个UBE。它提供很高的输入电阻和电流增益，但输出摆幅会受到额外结压降限制。

2.7.3 阻容耦合：先算后一级，再回头算前一级

第一级的实际交流负载是它的集电极电阻与第二级输入电阻并联；第二级再接最终RL。先算Ri2，再算带这个负载的Au1，最后 Au=Au1Au2。总输入电阻取第一级，总输出电阻取末级。

跟着算：教材2.2的静态工作点

按题给 RB=200kΩ、RC=5kΩ、VCC=12V、UBE=0.6V、β=25：

① 基极回路：IBQ=(12−0.6)/200k=57μA。
② 集电极电流：ICQ=25×57μA=1.425mA。
③ 集电极回路：UCEQ=12−1.425mA×5kΩ=4.875V。
④ 检查：VC=4.875V>VB=0.6V，集电结反偏，放大区假设成立。

3.1 结型场效应管JFET

  • JFET分为N沟道、P沟道；依靠电场改变导电沟道宽度控制漏极电流ID；属于电压控制型器件，输入几乎不取电流，输入电阻极高。
  • N沟道JFET：VGS≤0（通常栅源反偏）；VDS>0。
  • 转移特性：ID=IDSS(1-VGS/VP)2；IDSS饱和漏极电流；VP夹断电压。
  • 三个工作区：恒流区（放大区）、可变电阻区、夹断区。放大必须工作在恒流区。

3.2 MOS场效应管

  • 四类MOS管：N沟道增强型、N沟道耗尽型；P沟道增强型、P沟道耗尽型。
  • N沟道增强型：VGS必须大于开启电压VGS(th)才有导电沟道；耗尽型原始就存在沟道。
  • 沟道长度调制效应：VDS增大，有效沟道变短，ID轻微上升。
  • MOS管输入电阻极高；主要参数VGS(th)开启电压；VGS(off)夹断电压；IDSS；PDM最大耗散功率。
场效应管：电压控制电流源；BJT是电流控制电流源；FET输入电阻远高于BJT。

3.3 场效应管放大电路

  • 组态：共源（对应BJT共射，反相放大）；共漏（源极跟随器，对应共集，电压跟随）；共栅（对应共基，同相放大）。
  • 直流偏置方式：自给偏压电路（只适合耗尽型JFET/MOS）；分压式自偏置电路（增强/耗尽MOS通用）。
场效应管小信号参数：gm = ∂iD/∂uGS（跨导，单位mS）
共源电压增益 Au = −gm(Rd//RL)
输入电阻Ri很大；输出电阻Ro≈Rd

3.1 JFET：“夹断”不一定是截止

N沟道JFET正常放大时，栅结反偏。漏端沟道刚夹断后，电流并不立刻为零，而进入近似恒流区；只有栅源电压达到截止电压，沟道整体难以导电，漏极电流才近似为零。

设UP=UGS(off)<0：
UP≤UGS≤0，且UDS≥UGS−UP时，
ID≈IDSS(1−UGS/UP)²
gm=(2IDSS/|UP|)(1−UGSQ/UP)

3.2 N增强、N耗尽和P沟道

N增强型在UGS=0时通常没有导电沟道；N耗尽型在零栅压时已有沟道，负栅压削弱、正栅压增强。P沟道用USG、USD和阈值绝对值判断更清楚，电流与电压极性对应反转。

N增强型，令VOV=UGS−UT：
截止：VOV≤0；可变电阻区：0≤UDS<VOV；饱和区：UDS≥VOV>0。
若定义 ID=K VOV²，则 gm=2K VOV=2IDQ/VOV。

不同书可能把1/2放进K，也可能写在式子前面，代数值前先核对定义。MOS的“饱和区”是常用放大区，和BJT“饱和后不能线性放大”含义不同。

3.2.4 沟道长度调制

恒流区的曲线仍略向上倾斜，可以用 ID≈K VOV²(1+λUDS)描述，小信号输出电阻近似ro≈1/(λIDQ)。若不可忽略，共源的交流负载还要并联ro。

3.3 解二次方程之后，一定筛根

先用IG≈0求栅极电位，再写 UGS=UG−IDRS，与器件方程联立。所得根必须满足所假定工作区，且计算UDS后再次检查。图解法就是把偏置直线与转移曲线求交点。

共源，未旁路RS且忽略ro：Au≈−gmR′D/(1+gmRS)
共漏：Au≈gmR′S/(1+gmR′S)
共栅：Au≈+gmR′D，器件输入电阻约1/gm

“栅极不取电流”不代表整个放大电路输入电阻无穷大：偏置电阻会限制Ri。共漏输出电阻约RS∥1/gm，前提是忽略体效应和ro。

4.1 RC单时间常数电路频率响应

  • RC高通电路：对应放大电路低频段，耦合、旁路电容起作用；频率越低增益越小，相位超前。下限截止频率 fL=1/(2πRC)。
  • RC低通电路：对应放大电路高频段，PN结极间电容起作用；频率越高增益越小，相位滞后；上限截止频率 fH=1/(2πRC)。
  • 截止频率定义：增益下降到中频增益0.707倍（-3dB）的频率点。

4.2 BJT高频混合π模型

  • 混合π模型引入结电容Cb'e、Cb'c；密勒效应：Cb'c等效到输入端电容被放大，造成高频特性变差。
  • 特征频率fT：β下降为1时的信号频率，表征BJT高频能力。

4.3 单级共射放大电路频率响应

  • 中频区：耦合电容、旁路电容视为短路；极间电容视为开路；增益Aum恒定。
  • 低频区：耦合/旁路电容容抗增大，增益下降，产生附加相移。
  • 高频区：晶体管极间电容起作用，密勒效应使增益随频率升高下降。
  • 通频带BW = fH − fL，一般fH≫fL，BW≈fH。
  • 在相应单主极点近似及限定条件下，|Aum·BW|可近似为常数；不是任意放大器的普遍定律。
  • 多级放大电路：只有各级截止频率相差很大时，才可用最大的fLi和最小的fHi近似；一般应由总幅频特性求-3 dB点；多级之后带宽变窄。
阻容耦合放大电路fL不能等于0，不能放大直流；直接耦合放大电路fL=0，通带从0Hz开始。

4.1 幅频、相频、dB

低通 H(jω)=H₀/(1+jωRC)
高通 H(jω)=H∞·jωRC/(1+jωRC)
电压增益的分贝数：20log₁₀|Au|；ω=2πf

一阶低通在截止点相移−45°，远高于截止频率时幅频渐近线每十倍频下降20dB；一阶高通在截止点相移+45°，低频渐近线每十倍频上升20dB。共射的反相还要另外计入，不能把RC附加相移当总相位。

4.2.1～4.2.3 混合π、β截止频率与共基

混合π模型包括rb′e、gmvb′e受控源、Cb′e和Cb′c，必要时还包括基区电阻和输出电阻。结电容在中频近似开路，在高频必须保留。

单极点近似：β(jf)=β₀/(1+jf/fβ)
fT=fβ√(β₀²−1)≈β₀fβ（β₀≫1）
α=β/(1+β)，对应fα≈(1+β₀)fβ

fβ是β下降至中频值的0.707倍处；fT是|β|=1处。共基电流增益虽然小于1，但其截止频率通常比共射电流增益的截止频率高得多。

4.3.1 找电容“看见”的电阻

估计某个拐点时，计算电容两端看到的等效电阻，不能随便选图上最近的电阻。耦合电容通常看到两侧等效电阻之和；射极旁路电容还会看到经晶体管折算的低阻通路。

单个低频极点：fL≈1/(2πReqC)
共射密勒近似：Cin≈Cb′e+(1−Av)Cb′c
输入极点占主导时：fH≈1/(2πRin,eqCin)

4.3.2～4.3.3 改善频响与级联

降低高阻节点的等效电阻、减弱密勒效应、采用共射—共基组合，都能改善高频性能，但应同时检查增益、负载和功耗。增益带宽积近似恒定只适用于相应单主极点模型或限定参数变化，不能推广到任意放大器。

n个相同、相互加载已计入的单极点级联：
fH,total=fH,单级√(21/n−1)
fL,total=fL,单级/√(21/n−1)

总增益相乘、相位相加、dB相加。检查波形失真时，还要同时看输入频率是否在通带内，以及输出幅度是否超过线性摆幅。

5.1-5.3 零点漂移（温漂）

  • 直接耦合放大电路，输入短路输出电压随温度、电源缓慢变化，称为零点漂移，主要来源是温度变化。
  • 抑制零点漂移最有效单元电路：差分放大电路。
  • 温漂抑制手段：精选匹配对管；恒流源代替发射极电阻；温度补偿。

5.4 差分放大电路分析

  • 输入信号分解：差模信号uid；共模信号uic。
    ui1 = uic + uid/2 ； ui2 = uic − uid/2
  • 差模增益Aud：差模输入对应的电压增益；共模增益Auc：共模输入对应的电压增益，理想差分Auc=0。
  • 共模抑制比 KCMR = |Aud / Auc|；单位dB：KCMR(dB)=20lg|Aud/Auc|；KCMR越大，抑制温漂能力越好。

四种接法对比

  1. 双端输入-双端输出：Aud=-βR'L/rbe；Auc=0；输出无接地；适合级间。
  2. 双端输入-单端输出：Aud= −βR'L/(2rbe)；Auc很小但不为0；输出对地。
  3. 单端输入-双端输出：差模增益同双入双出；输入一端接地。
  4. 单端输入-单端输出：差模部分同双入单出，另需考虑单端输入带来的共模部分。
  • 发射极恒流源差分放大电路：等效极大Re，极大抑制共模，显著提高KCMR。恒流源对差模信号无反馈。

5.5 电压传输特性；5.6 性能指标汇总表

  • 差放电压传输特性uo=f(uid)；输入差模信号大时，尾电流逐渐转向一侧，传输特性不再线性。

补齐：差模等效、共模等效与负载折算

5.1～5.4 为什么两只管能抑制温漂

匹配器件受温度影响时，两支路电流往往同方向变化；取两个集电极电压之差时，共同变化相减。差模输入则让一边增大、另一边减小，相减后有效信号增强。零漂还可能来自电源变化与器件不匹配，并非只有温度一个原因。

静态对称时，两支路平分尾电流：IE1Q=IE2Q≈IT/2。先由尾电阻或恒流源求IT，再算各管Q点与rbe。

5.4.3～5.4.5 先定义差和共，再套增益

uid=ui1−ui2；uic=(ui1+ui2)/2
差模：两输入分别为+uid/2、−uid/2
共模：两输入都为uic

纯差模时，公共发射极节点为交流虚地。双端输出若跨接一个RL，半电路中每一边看到的是RL/2，因此R′C=RC∥(RL/2)。单端输出负载对地时，按实际支路接法重新列方程。

单端输入ui1=ui、ui2=0，并不是“只有差模”：它同时包含uid=ui和uic=ui/2。严格计算需把差模输出与共模输出相加。

5.4.6 尾电流源的意义

共模半电路中，每侧看到的尾电阻是2RE。单端共模增益可近似写成 −βRC/[rbe+2(β+1)RE]（对称、空载、忽略输出电阻）。尾电流源动态电阻越大，共模增益越小。完全对称的双端输出共模增益理想为零，实际失配会使其不为零。

5.5～5.6 从线性放大到电流转向

理想匹配双管、忽略基极电流时：
IC1−IC2≈ITtanh[uid/(2UT)]

输入差值很小时曲线近似直线；差值很大时尾电流几乎全部流入一侧，不能继续按小信号增益外推。四种接法的比较必须保持uid和输出极性定义一致；单端从另一侧取输出，增益符号反转。

6.1 集成运放概述

  • 集成运放内部四部分：输入级（差分放大，高KCMR）；中间级（高增益，共射放大）；输出级（互补功率输出，低输出电阻）；偏置电路（恒流源给各级提供静态电流）。
  • 运放引脚：同相输入端(+)，反相输入端(-)，输出端，正负电源。
  • 电压传输特性：线性区（输出受输入差值控制）；饱和限幅区（输出达到正负电源接近值）。

6.2 理想集成运算放大器

  • 理想运放参数：开环差模增益Aod→∞；差模输入电阻Rid→∞；输出电阻Ro→0；KCMR→∞。
  • 两大重要结论：
    ①虚短：线性工作区，u+ ≈ u-（输入差模电压近似为0）
    ②虚断：i+ ≈ 0 ，i- ≈ 0，输入端不取电流
    • 虚短只适用于线性负反馈分析；理想模型的虚断在比较器分析中也可使用。

6.3 理想运放线性应用（负反馈闭环）

1）反相比例运算电路

uo = − (Rf / R1) · ui
电压增益 Auf = − Rf/R1
同相端接地，反相端虚地：u-≈0

2）同相比例运算电路

uo = (1 + Rf/R1) · ui
Auf = 1 + Rf/R1
电压跟随器（Rf=0、R1开路）：uo=ui，Auf=1，输入电阻极高，输出电阻极低。

3）加法运算电路（反相加法）

uo = − Rf ( ui1/R1 + ui2/R2 + ui3/R3 )

4）减法运算电路（差分运算）

当 R1=R2，Rf=R3：
uo = (Rf/R1)(ui2 − ui1)

5）积分运算电路

uo = − (1 / R1C) ∫ ui dt
输入恒定正电压，输出线性下降；输入恒定负电压，输出线性上升。积分表达式还应加上初始输出电压。

6）微分运算电路

uo = − RfC · dui/dt
对输入信号的变化速率敏感，抗干扰差。

6.4 理想运放非线性应用（无负反馈，开环/正反馈）

  • 单门限电压比较器：无负反馈，只有虚断，无虚短；同相端电压大于反相端时输出正向饱和，反之负向饱和；输入信号接在哪一端决定输出极性。可以实现过压检测、电平判别。
  • 迟滞电压比较器（施密特比较器）：引入正反馈，存在上门限UT+、下门限UT-；回差电压ΔUT=UT+−UT-；抗噪声能力强，用于波形整形。

补齐：运放题最重要的是先判工作区

6.1～6.2 理想模型和实际限制

在线性负反馈且输出未饱和时，才能用虚短；理想输入电阻无穷大带来的虚断，也可以用于理想比较器分析。实际运放还受失调电压、输入偏置电流、共模范围、输出摆幅、带宽、转换速率限制。题目给出这些参数时，应检查结果是否超限。

6.3 不背复杂公式，直接列节点电流

先求同相端电位，再令反相端与它近似相等；用虚断在反相端列KCL。多个输入分别写电流，电容写 i=C·du/dt，就能统一推导比例、加减、积分与微分。

减法电路明确约定：u₁经R₁接负端，Rf反馈；u₂经R₂接正端，正端经R₃接地。
uo=(1+Rf/R₁)·[R₃/(R₂+R₃)]u₂−(Rf/R₁)u₁
当Rf/R₁=R₃/R₂时，uo=(Rf/R₁)(u₂−u₁)。

积分器 uo(t)=uo(t₀)−(1/RC)∫t₀tui(τ)dτ。分段波形题要把上一段末值作为下一段初值，并检查是否达到输出限幅；理想微分器对突变给尖脉冲，实际峰值受带宽与摆幅限制。

6.4.1～6.4.2 迟滞门限的通用算法

先假设输出为高电平UOH，求正反馈节点电位，令u+=u−得到一个翻转门限；再假设输出为低电平UOL，同样求另一个门限。最后沿输入上升、下降方向检查输出如何翻转。比较器并非始终满足虚短，只有在求临界翻转条件时才令两输入相等。

若输入接负端，正端通过Ro接输出、通过Rr接基准UREF：
u+=(Rruo+RoUREF)/(Ro+Rr)。
分别代入UOH、UOL得到两门限。

6.4.3～6.4.4 集成比较器与运放的区别

比较器为快速翻转设计；有些采用集电极开路输出，需要上拉电阻才能形成高电平。输出高低电平由输出结构、上拉电源及负载决定，不能默认等于供电轨。迟滞比较器有两个门限，能避免输入在单门限附近叠加噪声时反复跳变；单门限比较器则没有这段回差。

7.1 反馈基本概念与分类

  • 反馈：把输出回路信号（电压/电流）取出一部分，送回到输入回路，与输入信号叠加。
  • 分类1：直流反馈、交流反馈。直流反馈影响静态Q点；交流反馈改善动态性能指标。
  • 分类2：正反馈、负反馈。瞬时极性法判断正负反馈。
    瞬时极性步骤：假设输入对地+ →逐级标出每一级输入输出极性 →看反馈信号送到输入端是削弱输入（负反馈）还是增强输入（正反馈）。
  • 分类3：串联反馈、并联反馈（看输入回路叠加方式）
    串联：反馈信号与输入信号电压相加减；并联：反馈信号与输入信号电流相加减。
  • 分类4：电压反馈、电流反馈（输出短路判别法）
    输出短路法：令uo=0（输出对地短路）；反馈消失=电压反馈；反馈还存在=电流反馈。
    电压反馈：稳定输出电压；电流反馈：稳定输出电流。

7.2 四种负反馈组态

  1. 电压串联负反馈：稳定输出电压，输入电阻增大，输出电阻减小。
  2. 电压并联负反馈：稳定输出电压，输入电阻减小，输出电阻减小。
  3. 电流串联负反馈：稳定输出电流，输入电阻增大，输出电阻增大。
  4. 电流并联负反馈：稳定输出电流，输入电阻减小，输出电阻增大。

7.3 闭环增益一般表达式

Af = A / (1+AF)
反馈深度： 1+AF；|1+AF| ≫ 1 称为深度负反馈。

7.4 负反馈对放大电路性能的影响

  • 1）降低闭环增益，提高增益的稳定性。
  • 2）改变输入电阻：串联负反馈 → Ri↑；并联负反馈 → Ri↓。
  • 3）改变输出电阻：电压负反馈 → Ro↓（输出接近恒压源）；电流负反馈 → Ro↑（输出接近恒流源）。
  • 4）减小非线性失真，拓展通频带。
    • 负反馈对噪声的影响取决于噪声注入位置与环路；不能笼统认为会消除所有噪声。深度负反馈条件下，虚短虚断思想可以用于分立负反馈估算。

7.5 深度负反馈近似计算

  • 深度负反馈条件：|1+AF| ≫1 → Xi ≈ Xf（净输入近似为0）。
    串联负反馈：ui ≈ uf；并联负反馈：ii ≈ if。
  • 根据组态，直接写出反馈信号，再求解闭环电压增益Auf=uo/ui。

补齐：四种反馈分别在“放大什么”

7.1 判断顺序

先找输出回到输入的通路，再在直流/交流等效图上分别判断。瞬时极性法要观察反馈是否削弱净输入，不能仅凭反馈接到某个电极就断定正负。输出短路法是小信号理论判别，不是让你实际短接带电输出。

7.2～7.3 A和F的量纲要配对

组态开环增益A反馈系数F深反馈结果1/F
电压串联uo/uduf/uo电压增益
电压并联uo/id（Ω）if/uo（S）互阻增益（Ω）

7.4 性能变化的定量关系

F固定、负反馈模型成立时：
(dAf/Af)/(dA/A)=1/(1+AF)
串联输入：Rif≈Ri(1+AF)；并联输入：Rif≈Ri/(1+AF)
电压取样：Rof≈Ro/(1+AF)；电流取样：Rof≈Ro(1+AF)

这些是标准反馈模型中的关系，反馈网络加载不能漏掉。高频相移可能使原本的负反馈变成正反馈，因此“反馈越深越好”并不总成立。

7.5 解题落笔顺序

  1. 标净输入量、输出量、反馈量及参考方向。
  2. 串联令净输入电压近似零；并联令净输入电流近似零。
  3. 用反馈网络KCL/KVL写输入—输出关系。
  4. 换算到题目要求的增益，检查负号与量纲。

8.2 OCL乙类互补对称功放（双电源）

最大效率 ηmax = π/4 ≈78.5%
单管最大平均管耗 PT1max = VCC²/(π²RL) ≈ 0.203 Pomax

Pomax = (VCC/2)² / (2RL) = VCC²/(8RL)

8.1 导通角与功率

甲类导通360°；乙类每管约180°；甲乙类每管大于180°而小于360°。功率题首先注明Uom是正弦峰值，Uo是有效值；有效值为峰值/√2。

8.2 任意输出幅度下的乙类OCL

对称±VCC、理想乙类、纯电阻负载：
Po=Uom²/(2RL)
PV=2VCCUom/(πRL)
η=πUom/(4VCC)
两管总耗散 PT=PV−Po

单管最大发热发生在 Uom=2VCC/π 附近，而不是最大输出幅度处。此时每管最大平均管耗为 VCC²/(π²RL)。选管还需核对最大电流约Uom,max/RL、截止管耐压约2VCC，并考虑实际裕量。

考虑饱和及驱动限制，Uom,max通常小于VCC，常用近似VCC−UCE(sat)。甲乙类有静态功耗，不能机械使用理想乙类效率式。

8.3 单电源OTL的两个“输出电位”

电容前的输出中点静态约VCC/2；电容后的负载端直流约0。可用交流摆幅约VCC/2，故理想最大功率为VCC²/(8RL)。隔直电容与负载形成低频限制；容量太小，低频输出会衰减。

交越失真来自两个管子在零点附近都未充分导通。二极管或偏置网络给两发射结预置小电流，可减小死区；偏置过大又会增加静态发热。

9.1.1～9.1.2 一阶与二阶的区别

有源滤波器依靠运放提供增益与隔离；RC网络决定选频。先把电容写成阻抗1/(sC)，用节点方程求H(s)，再令s=jω。阶数由传递函数分母的最高次数决定，不是只数图上的电容。

9.1.3～9.1.6 二阶标准形式

令 D(s)=s²+(ω₀/Q)s+ω₀²，ω₀为固有角频率，Q为品质因数。下面A₀表示相应通带或中心频率增益，具体大小由实际电路确定。

类型H(s)看两端和中心
低通A₀ω₀²/D(s)低频通过，高频衰减
高通A₀s²/D(s)直流被阻，高频通过
带通A₀(ω₀/Q)s/D(s)两端衰减，ω₀附近通过
带阻A₀(s²+ω₀²)/D(s)理想在ω₀处零输出

二阶低通/高通的远端滚降为40dB/十倍频；二阶带通的两侧各20dB/十倍频。标准带通BW=f₀/Q，Q越大通带越窄。二阶低通的ω₀不总是−3dB截止频率；Q=1/√2的巴特沃思形式才重合。

9.2.1 起振和稳幅分别是谁负责

直流电源提供能量，放大环节补偿损耗，选频网络选择频率，正反馈维持振荡，非线性稳幅使有效环路增益回到1。没有外加周期输入也能产生周期输出，但不能没有电源。

9.2.2～9.2.3 文氏桥与RC移相

文氏桥两组R、C相等时，f₀=1/(2πRC)，选频反馈系数为1/3，稳态放大倍数约3、起振略大于3。RC移相振荡由反相放大器提供180°，RC链再提供180°。常见三级等值、无缓冲RC梯形移相网络在理想驱动/负载条件下有 f₀≈1/(2πRC√6)、最小放大倍数约29；实际网络若受加载，必须重新求相位与幅值条件。

9.2.4 LC三点式

按交流等效电路判断反馈极性。电容三点式的谐振电容通常是C₁、C₂串联等效：Ceq=C₁C₂/(C₁+C₂)，f₀≈1/(2π√(LCeq))。电感三点式需按线圈同名端考虑互感，不能永远用L₁+L₂。变压器反馈同样必须看绕组极性。

9.2.5 石英晶体

等效电路包括动态R、L、C支路及静态电容；存在串联、并联谐振频率。两者很接近，品质因数很高，因此选频尖锐、频率稳定。晶体在不同频段表现为不同电抗，需结合具体振荡接法判断。

9.3 方波：门限+指数充放电

若比较器对称输出±UO、门限±kUO（0<k<1），电容经R向输出充放电：
T=2RC·ln[(1+k)/(1−k)]

先由反馈分压求k，再代公式，可以避免不同图中R₁、R₂命名相反造成错套。更一般地，用uC(t)=U∞+[uC(0)−U∞]e−t/RC，从一个门限算到另一个门限。

9.4 三角波与锯齿波

比较器输出恒定正/负电平时，积分器输出线性升降，斜率duo/dt=−uin/(RC)。两段斜率绝对值相同得到对称三角波；用二极管和不同电阻使充、放电速度不同，得到锯齿波。每段时间=该段电压变化量÷斜率绝对值，周期是两段之和。

10.2 怎样评价稳不稳

稳压系数描述输入电压变化传到输出的比例，常用 S=(ΔUO/UO)/(ΔUI/UI)；输出电阻用|ΔUO/ΔIO|描述负载变化引起的电压变化。纹波是直流上叠加的周期波动，纹波系数常为纹波交流有效值与直流平均值之比。不同指标的测试条件应保持一致。

10.3.4 电容、电感与复合滤波

电容并在负载两端：电压峰值附近充电，其他时间向负载放电；电感串联利用电流连续性抑制脉动。RC、LC或π型滤波继续削弱纹波，但带来压降、体积或功耗的代价。

小纹波、电容滤波近似：ΔUpp≈IL/(frippleC)

半波电容滤波的二极管反向峰值可能接近2√2U₂，不能套用“无滤波半波”的耐压。桥式带载1.2U₂是特定RC范围的经验值，不是恒定公式；轻载时更接近峰值。

10.3.5 倍压整流

利用不同半周为不同电容充电，再将电容电压串叠。理想空载倍压可得到约峰值的整数倍，但带载后电压下降、纹波增大。分析时逐半周画导通回路，标每个电容的正负极性，再按指定输出端求电压代数和；二极管耐压需要从截止半周单独计算。

10.4 串联反馈稳压的闭环过程

输出下降→采样电压下降→比较放大器使调整管更导通→调整管压降减小→输出回升。实际极性应按电路验证。稳压范围还要求输入最低谷值高于输出与调整管所需压差之和。

UO=UREF(1+R₂/R₁)+IADJR₂
线性稳压器主要损耗近似 P≈(UI−UO)IO

检查最小负载电流、输入输出压差、最大电流与散热。78XX/79XX的正负极性和引脚连接应按题图或器件资料，不能把正负稳压器按同一引脚顺序接线。
