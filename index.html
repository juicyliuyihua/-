第1章 半导体二极管及其基本应用电路

1.1 半导体的基础知识

1.1.1 本征半导体

  • 纯净硅/锗晶体，依靠共价键结合；受热、光照发生本征激发，产生成对自由电子-空穴对。
  • 两种载流子参与导电：电子（负）、空穴（正）；金属导电通常用自由电子模型描述。
  • 载流子不断产生、复合，达到动态平衡；温度越高，载流子数量越多，导电能力越强。室温本征载流子浓度很低。

1.1.2 N型、P型杂质半导体

  • N型半导体（掺五价磷）：多子=自由电子；少子=空穴。
  • P型半导体（掺三价硼）：多子=空穴；少子=自由电子。
  • 重要结论：N/P半导体整体电中性；多子浓度由掺杂浓度决定；少子浓度主要受温度控制。

1.2 PN结的形成及特性

1.2.1 PN结形成

  • 同一块晶片一边做P区，一边N区；浓度差引发多子扩散运动；交界面留下不可移动正负离子，形成空间电荷区（耗尽层、内电场）。
  • 内电场阻碍扩散，推动少子漂移运动；无外加电压，扩散电流=漂移电流，动态平衡，形成PN结。

1.2.2 PN结单向导电性

  • 正向偏置：P接电源+，N接-：外电场抵消内电场，耗尽层变窄；扩散>>漂移，PN结导通，正向电流大。
  • 反向偏置：P接-，N接+：耗尽层变宽；只有微弱少子漂移，反向饱和电流IS很小，近似截止。
易错：PN结直接短路，金属接触电势抵消内建电势，不会产生持续电流。

1.3 半导体二极管

  • 二极管 = PN结 +引线外壳；P引出阳极，N引出阴极；分点接触、面接触、平面型。
  • 伏安特性：硅管死区电压约0.5V，导通压降0.6~0.8V；锗管死区约0.1V，导通压降0.2~0.3V；反向电压超过击穿电压发生反向击穿。
  • 主要参数：最大整流电流IF；最高反向工作电压UR；反向电流IR；极间电容Cd；反向恢复时间TRR。

1.4 二极管基本电路及分析方法

1.4.1 四种等效模型

  1. 理想模型：正向压降0V，反向电流0；适合电源电压远大于管压降。
  2. 恒压降模型：硅管导通固定0.7V，反向截止；按题目规定采用此近似。
  3. 折线模型：死区Uth=0.5V + 微变电阻rd。
  4. 小信号微变模型：仅Q点微小交流信号。
    rd = UT / ID ≈ 26mV / ID(mA) （常温T=300K）
rd和静态直流ID强相关，直流电流越大微变电阻越小。

1.4.2 模型分析法解题步骤

  1. 断开二极管，分别求阳极、阴极电位，得到开路电压。
  2. 理想模型中V阳极 > V阴极可判断正向导通；恒压降模型还需检查规定压降，替换对应等效模型。
  3. V阳极 < V阴极：二极管截止，支路断开，I=0。
  4. 多二极管电路：正向开路电压最大的优先导通，导通钳位电位，再判断其余管子状态。

1.4.3 二极管典型应用

  • 开关逻辑电路；半波/桥式整流；单向/双向限幅；多管串联低压稳压。

1.5 特殊二极管

  • 稳压二极管（齐纳管）：正常工作在反向电击穿区，击穿可逆；电流必须限制IZ ~ IZM。
    参数：UZ稳定电压；IZ稳定电流；IZM最大稳定电流；动态电阻 rZ=ΔUZ/ΔIZ，rZ越小稳压越好；PZM=UZIZM。
  • LED发光二极管：正向导通发光；光电二极管：反向偏置，光照越强反向电流越大；变容二极管：反向电压改变结电容；肖特基二极管：开关速度高，正向压降低。

第2章 双极结型晶体管及其放大电路

2.1 BJT双极结型晶体管

  • 类型NPN、PNP；三个区域：发射区、基区、集电区；两个PN结：发射结、集电结；电极e发射极，b基极，c集电极。
  • 关键结构特点：基区很薄，掺杂浓度很低；发射区掺杂浓度高；集电区面积大；发射区-集电区不对称，不能互换使用。

BJT三种工作状态（NPN硅管）

  1. 放大状态：发射结正偏，集电结反偏；电位VC > VB > VE
    IE = IB + IC； IC ≈ β IB； IE ≈ (1+β) IB
    本质：小基极电流IB控制大集电极电流IC。
  2. 饱和状态：发射结正偏，集电结正偏；VB > VC；IC不再随IB成β倍增大；硅管饱和压降UCES≈0.3V。
  3. 截止状态：发射结未充分正向导通，集电结通常反偏；IB≈0，IC≈0。
PNP管全部电压极性反转；放大状态电位VE > VB > VC，UEB>0。

BJT主要参数

  • 直流β̄，交流β；α=β/(1+β)；ICBO集电结反向饱和电流；穿透电流 ICEO=(1+β)ICBO。
  • 极限参数：ICM最大集电极电流；PCM为最大允许耗散功率；静态管耗PC≈ICUCE；反向击穿电压关系 U(BR)CBO > U(BR)CES > U(BR)CER > U(BR)CEO。

阻容耦合共射放大电路示意图

2.2-2.3 共射放大电路；图解法、小信号模型分析法

静态工作点Q（直流通路：耦合电容全部开路）

IBQ = (VCC − UBEQ) / Rb
ICQ ≈ β IBQ
UCEQ = VCC − ICQ Rc
  • Q点过低IBQ太小：截止失真，输出电压顶部被削平。
  • Q点过高IBQ太大：饱和失真，输出电压底部被削平。
  • 输入幅度增大时先触及余量较小的一侧，继续增大可能出现双向削顶。

小信号模型动态分析（中频：电容近似短路，理想直流电源交流接地）

rbe ≈ 200Ω + (1+β) · 26mV / IEQ(mA)
适用于发射极交流接地、忽略rce的共射电路：
Au = uo/ui = − β(Rc//RL) / rbe
Ri = Rb // rbe
Ro ≈ Rc
Au负号代表共射电路输出输入相位反相180°；小信号模型只计算交流变化分量，不能用来求静态直流Q点。

2.4 分压式射极偏置电路（稳定静态工作点）

以下分压近似需满足 Rb1∥Rb2 ≪ (β+1)Re。不满足时，先作戴维南等效：VBB=VCCRb2/(Rb1+Rb2)，RB=Rb1∥Rb2；假设放大区，IBQ=(VBB−UBEQ)/[RB+(β+1)Re]，算完检查工作区。

  • 满足I1 ≫ IBQ，基极电位近似由电阻分压得到，VBQ基本不受温度影响。
  • 发射极电阻Re引入直流负反馈抑制ICQ随温度升高；并联旁路电容Ce消除Re对交流信号衰减。
VBQ ≈ Rb2/(Rb1+Rb2) · VCC
IEQ = (VBQ − UBEQ) / Re
UCEQ ≈ VCC − IEQ(Rc+Re)

2.5 共集电极放大电路（射极跟随器）

  • 电压放大倍数Au≈+1，小于1；输入电阻很高，输出电阻很低；电压跟随，电流放大。
  • 典型用途：输入缓冲隔离、输出级驱动低阻负载。

2.6 共基极放大电路

  • 电压增益高，输出输入相位同相；输入电阻很小，输出电阻大；高频特性优异。

2.7 多级放大电路

  • 耦合方式：
    ①阻容耦合：隔直，各级静态Q相互独立，不能放大直流和缓慢变化信号；
    ②直接耦合：可以放大直流信号，存在零点漂移问题。
  • 总电压增益：Au = Au1·Au2·Au3…；总输入电阻等于第一级输入电阻；总输出电阻等于最后一级输出电阻。

第2章复习题型与解题思路（非教材原题编号）

2.1 根据BJT三个电极电位，判断NPN/PNP，判断工作状态：放大、饱和、截止。

查看解题思路
NPN放大条件：UBE>开启电压，VC>VB>VE；饱和VB>VC；截止UBE小于死区。PNP电位全部反过来。

2.2 已知BJTβ、ICBO，求ICEO，IB，IC，IE。

查看解题思路
ICEO=(1+β)ICBO；IC=βIB+ICEO；IE=IB+IC。

2.3 固定偏置共射电路，给定VCC，Rb，Rc，β；求静态IBQ，ICQ，UCEQ，判断管子是否工作在放大区。

查看解题思路
直流通路电容开路；先算IBQ，再ICQ；计算UCEQ；UCEQ>UBEQ则放大；若UCEQ接近0.3V进入饱和。

2.4 图解法，给出输出特性曲线，Rc、VCC画直流负载线，读出Q点参数。

查看解题思路
直流负载线两点：(VCC,0)，(0,VCC/Rc)；负载线和IB对应输出特性交点即Q点，读出ICQ、UCEQ。

2.5 共射放大电路，参数已知，求rbe，Au，Ri，Ro；负载RL开路Au如何变化。

查看解题思路
先求静态IEQ；计算rbe；带负载用Rc//RL；RL开路后，增益分子中的并联负载变为Rc，电压增益绝对值变大。

2.6 固定偏置共射，说明Rb增大、Rc增大、VCC增大分别如何影响静态Q点，会产生什么失真。

查看解题思路
Rb↑ →IBQ↓，Q下移，容易截止失真；Rc↑ →UCEQ下降，容易饱和失真；VCC改变时需重算IBQ、ICQ及UCEQ，不能一概判断动态范围增大。

2.7 分压式射极偏置电路，带Ce；给定VCC，Rb1、Rb2，Rc，Re，β，RL；求静态Q点；求Au、Ri、Ro。

查看解题思路
第一步分压算VBQ；第二步IEQ=(VBQ-UBEQ)/Re；算UCEQ；再求rbe；Ce存在Re交流接地，代入增益输入输出电阻公式。

2.8 射极跟随器（共集），已知电路参数，求静态Q；求Au、Ri、Ro。

查看解题思路
直流通路求IBQ、IEQ；rbe；共集Au≈(1+β)R'L/(rbe+(1+β)R'L)；输入电阻大，输出电阻很小。

2.9 共基放大电路参数给定，求静态Q点，Au，Ri，Ro。

查看解题思路
静态计算和分压偏置一致；共基电压增益为正，同相；输入电阻很小Ri≈rbe/(1+β)；输出电阻≈Rc。

2.10 两级阻容耦合放大电路，每级参数已知，求总Au，总输入电阻Ri，总输出电阻Ro。

查看解题思路
后级输入电阻作为前级负载；Au=Au1×Au2；总输入电阻=第一级Ri1；总输出电阻=第二级Ro2。

第3章 场效应晶体管及其放大电路

3.1 结型场效应管JFET

  • JFET分为N沟道、P沟道；依靠电场改变导电沟道宽度控制漏极电流ID；属于电压控制型器件，输入几乎不取电流，输入电阻极高。
  • N沟道JFET：VGS≤0（通常栅源反偏）；VDS>0。
  • 转移特性：ID=IDSS(1-VGS/VP)2；IDSS饱和漏极电流；VP夹断电压。
  • 三个工作区：恒流区（放大区）、可变电阻区、夹断区。放大必须工作在恒流区。

3.2 MOS场效应管

  • 四类MOS管：N沟道增强型、N沟道耗尽型；P沟道增强型、P沟道耗尽型。
  • N沟道增强型：VGS必须大于开启电压VGS(th)才有导电沟道；耗尽型原始就存在沟道。
  • 沟道长度调制效应：VDS增大，有效沟道变短，ID轻微上升。
  • MOS管输入电阻极高；主要参数VGS(th)开启电压；VGS(off)夹断电压；IDSS；PDM最大耗散功率。
场效应管：电压控制电流源；BJT是电流控制电流源；FET输入电阻远高于BJT。

3.3 场效应管放大电路

  • 组态：共源（对应BJT共射，反相放大）；共漏（源极跟随器，对应共集，电压跟随）；共栅（对应共基，同相放大）。
  • 直流偏置方式：自给偏压电路（只适合耗尽型JFET/MOS）；分压式自偏置电路（增强/耗尽MOS通用）。
场效应管小信号参数：gm = ∂iD/∂uGS（跨导，单位mS）
共源电压增益 Au = −gm(Rd//RL)
输入电阻Ri很大；输出电阻Ro≈Rd

第3章复习题型与解题思路（非教材原题编号）

3.1 判断JFET、MOS管类型；根据VGS、VDS判断管子工作区域：恒流区、可变电阻区、夹断区。

查看解题思路
N沟道增强MOS：VGS>VGS(th)，同时VDS≥VGS-VGS(th)，进入恒流放大区。

3.2 N沟道JFET，已知IDSS、VP；给定VGS求ID。

查看解题思路
代入转移特性公式 ID=IDSS(1-VGS/VP)²，注意VP是负数。

3.3 自给偏压共源放大电路，求静态VGSQ，IDQ，VDSQ；再求gm，Au，Ri，Ro。

查看解题思路
VGSQ=0-IDQ·Rs，联立转移特性方程求解静态；gm求跨导，再代入共源增益公式。

3.4 分压式偏置共源MOS放大电路，求静态Q点；求动态Au、Ri、Ro。

查看解题思路
先算栅极分压VG；VGSQ=VG-IDQRs，联立MOS转移特性求解静态；跨导gm后算动态指标。

3.5 共漏（源极跟随器）电路参数已知，求静态Q；求Au、Ri、Ro。

查看解题思路
共漏Au≈gmR'L/(1+gmR'L)，电压跟随小于1；Ri极高，输出电阻Ro≈1/gm。

第4章 放大电路的频率响应

4.1 RC单时间常数电路频率响应

  • RC高通电路：对应放大电路低频段，耦合、旁路电容起作用；频率越低增益越小，相位超前。下限截止频率 fL=1/(2πRC)。
  • RC低通电路：对应放大电路高频段，PN结极间电容起作用；频率越高增益越小，相位滞后；上限截止频率 fH=1/(2πRC)。
  • 截止频率定义：增益下降到中频增益0.707倍（-3dB）的频率点。

4.2 BJT高频混合π模型

  • 混合π模型引入结电容Cb'e、Cb'c；密勒效应：Cb'c等效到输入端电容被放大，造成高频特性变差。
  • 特征频率fT：β下降为1时的信号频率，表征BJT高频能力。

4.3 单级共射放大电路频率响应

  • 中频区：耦合电容、旁路电容视为短路；极间电容视为开路；增益Aum恒定。
  • 低频区：耦合/旁路电容容抗增大，增益下降，产生附加相移。
  • 高频区：晶体管极间电容起作用，密勒效应使增益随频率升高下降。
  • 通频带BW = fH − fL，一般fH≫fL，BW≈fH。
  • 增益带宽积：|Aum·BW|≈常数；电压增益做的越大，带宽越窄。
  • 多级放大电路：只有各级截止频率相差很大时，才可用最大的fLi和最小的fHi近似；一般应由总幅频特性求-3 dB点；多级之后带宽变窄。
阻容耦合放大电路fL不能等于0，不能放大直流；直接耦合放大电路fL=0，通带从0Hz开始。

第4章复习题型与解题思路（非教材原题编号）

查看解题思路

查看解题思路

查看解题思路
低频由耦合电容、旁路电容分别算出多个fL，取最大为本级fL；高频受密勒电容决定fH；BW=fH-fL。

查看解题思路

第5章 差分式放大电路

5.1-5.3 零点漂移（温漂）

  • 直接耦合放大电路，输入短路输出电压随温度、电源缓慢变化，称为零点漂移，主要来源是温度变化。
  • 抑制零点漂移最有效单元电路：差分放大电路。
  • 温漂抑制手段：精选匹配对管；恒流源代替发射极电阻；温度补偿。

5.4 差分放大电路分析

  • 输入信号分解：差模信号uid；共模信号uic。
    ui1 = uic + uid/2 ； ui2 = uic − uid/2
  • 差模增益Aud：差模输入对应的电压增益；共模增益Auc：共模输入对应的电压增益，理想差分Auc=0。
  • 共模抑制比 KCMR = |Aud / Auc|；单位dB：KCMR(dB)=20lg|Aud/Auc|；KCMR越大，抑制温漂能力越好。

四种接法对比

  1. 双端输入-双端输出：Aud=-βR'L/rbe；Auc=0；输出无接地；适合级间。
  2. 双端输入-单端输出：Aud= −βR'L/(2rbe)；Auc很小但不为0；输出对地。
  3. 单端输入-双端输出：差模增益同双入双出；输入一端接地。
  4. 单端输入-单端输出：差模增益减半，同双入单出。
  • 发射极恒流源差分放大电路：等效极大Re，极大抑制共模，显著提高KCMR。恒流源对差模信号无反馈。

5.5 电压传输特性；5.6 性能指标汇总表

  • 差放电压传输特性uo=f(uid)；输入差模信号大时进入限幅饱和。

查看解题思路

第6章 集成运算放大器

6.1 集成运放概述

  • 集成运放内部四部分：输入级（差分放大，高KCMR）；中间级（高增益，共射放大）；输出级（互补功率输出，低输出电阻）；偏置电路（恒流源给各级提供静态电流）。
  • 运放引脚：同相输入端(+)，反相输入端(-)，输出端，正负电源。
  • 电压传输特性：线性区（输出受输入差值控制）；饱和限幅区（输出达到正负电源接近值）。

6.2 理想集成运算放大器

  • 理想运放参数：开环差模增益Aod→∞；差模输入电阻Rid→∞；输出电阻Ro→0；KCMR→∞。
  • 两大重要结论：
    ①虚短：线性工作区，u+ ≈ u-（输入差模电压近似为0）
    ②虚断：i+ ≈ 0 ，i- ≈ 0，输入端不取电流
    • 虚短、虚断只在线性区成立；非线性（比较器）只有虚断，没有虚短！

6.3 理想运放线性应用（负反馈闭环）

1）反相比例运算电路

uo = − (Rf / R1) · ui
电压增益 Auf = − Rf/R1
同相端接地，反相端虚地：u-≈0

2）同相比例运算电路

uo = (1 + Rf/R1) · ui
Auf = 1 + Rf/R1
电压跟随器（Rf=0、R1开路）：uo=ui，Auf=1，输入电阻极高，输出电阻极低。

3）加法运算电路（反相加法）

uo = − Rf ( ui1/R1 + ui2/R2 + ui3/R3 )

4）减法运算电路（差分运算）

当 R1=R2，Rf=R3：
uo = (Rf/R1)(ui2 − ui1)

5）积分运算电路

uo = − (1 / R1C) ∫ ui dt
输入恒定正电压，输出线性下降；输入恒定负电压，输出线性上升。积分表达式还应加上初始输出电压。

6）微分运算电路

uo = − RfC · dui/dt
对输入信号的变化速率敏感，抗干扰差。

反相比例运算电路示意图

6.4 理想运放非线性应用（无负反馈，开环/正反馈）

  • 单门限电压比较器：无负反馈，只有虚断，无虚短；同相端电压大于反相端时输出正向饱和，反之负向饱和；输入信号接在哪一端决定输出极性。可以实现过压检测、电平判别。
  • 迟滞电压比较器（施密特比较器）：引入正反馈，存在上门限UT+、下门限UT-；回差电压ΔUT=UT+−UT-；抗噪声能力强，用于波形整形。

第7章 反馈放大电路

7.1 反馈基本概念与分类

  • 反馈：把输出回路信号（电压/电流）取出一部分，送回到输入回路，与输入信号叠加。
  • 分类1：直流反馈、交流反馈。直流反馈影响静态Q点；交流反馈改善动态性能指标。
  • 分类2：正反馈、负反馈。瞬时极性法判断正负反馈。
    瞬时极性步骤：假设输入对地+ →逐级标出每一级输入输出极性 →看反馈信号送到输入端是削弱输入（负反馈）还是增强输入（正反馈）。
  • 分类3：串联反馈、并联反馈（看输入回路叠加方式）
    串联：反馈信号与输入信号电压相加减；并联：反馈信号与输入信号电流相加减。
  • 分类4：电压反馈、电流反馈（输出短路判别法）
    输出短路法：令uo=0（输出对地短路）；反馈消失=电压反馈；反馈还存在=电流反馈。
    电压反馈：稳定输出电压；电流反馈：稳定输出电流。

7.2 四种负反馈组态

  1. 电压串联负反馈：稳定输出电压，输入电阻增大，输出电阻减小。
  2. 电压并联负反馈：稳定输出电压，输入电阻减小，输出电阻减小。
  3. 电流串联负反馈：稳定输出电流，输入电阻增大，输出电阻增大。
  4. 电流并联负反馈：稳定输出电流，输入电阻减小，输出电阻增大。

7.3 闭环增益一般表达式

Af = A / (1+AF)
反馈深度： 1+AF；|1+AF| ≫ 1 称为深度负反馈。

7.4 负反馈对放大电路性能的影响

  • 1）降低闭环增益，提高增益的稳定性。
  • 2）改变输入电阻：串联负反馈 → Ri↑；并联负反馈 → Ri↓。
  • 3）改变输出电阻：电压负反馈 → Ro↓（输出接近恒压源）；电流负反馈 → Ro↑（输出接近恒流源）。
  • 4）减小非线性失真，拓展通频带。
    • 负反馈对噪声的影响取决于噪声注入位置与环路；不能笼统认为会消除所有噪声。深度负反馈条件下，虚短虚断思想可以用于分立负反馈估算。

7.5 深度负反馈近似计算

  • 深度负反馈条件：|1+AF| ≫1 → Xi ≈ Xf（净输入近似为0）。
    串联负反馈：ui ≈ uf；并联负反馈：ii ≈ if。
  • 根据组态，直接写出反馈信号，再求解闭环电压增益Auf=uo/ui。

第8章 功率放大电路

8.1 功放电路特点

  • 功率放大电路：输出大电压大电流，向负载输送功率；关注最大输出功率Pomax、电源功率PV、转换效率η、管耗PT。
    小信号电压放大：追求电压增益；功放追求输出功率与效率。
  • 工作类别：甲类（整个周期管子导通，电阻负载理想最高效率25%；变压器耦合理想最高50%）；乙类（半个周期导通，交越失真）；甲乙类（克服交越失真，静态微小偏置）。

8.2 OCL乙类互补对称功放（双电源）

  • 正负双电源+NPN、PNP互补管；静态输出为0V。乙类：无静态偏置，零点附近因死区电压产生交越失真。甲乙类增加微小正向偏置消除交越失真。
最大输出功率（理想，忽略饱和压降UCES）：
Pomax = VCC²/(2RL)
电源提供功率： PV = 2VCC²/(πRL)
最大效率 ηmax = π/4 ≈78.5%
单管最大管耗 PT1max ≈ 0.2 Pomax
功放管耐压 |U(BR)CEO| > 2VCC

8.3 OTL甲乙类单电源互补对称功放

  • 单电源VCC，输出经大电容隔直耦合到负载；静态电容充电电压≈VCC/2。等效电源V'=VCC/2。
Pomax = (VCC/2)² / (2RL) = VCC²/(8RL)

OCL功放示意图

乙类OCL最大效率78.5%是理想极限，实际电路小于该数值；交越失真解决方法：设置甲乙类微小静态偏置。

第9章 信号处理与信号产生电路

9.1 有源滤波电路

  • 滤波器功能：允许某一部分频率信号通过，抑制另外一部分频率。分为低通LPF、高通HPF、带通BPF、带阻BEF。
  • 一阶有源低通：运放+RC网络；二阶滤波，滤波的阻带衰减更快-40dB/十倍频。

9.2 正弦波振荡电路

  • 正弦波振荡两个条件：
    幅值条件：|A·F| = 1；
    相位条件：φA+φF = 2nπ，正反馈。
    起振条件：|A·F| >1；稳定后等于1。
  • RC桥式（文氏桥）正弦振荡：RC串并联选频网络，谐振频率 f0 = 1/(2πRC)；选频网络F=1/3，放大电路Auf>3才能起振。负反馈用来稳幅。
  • LC正弦振荡：变压器反馈、电感三点式、电容三点式；适合高频。
  • 石英晶体振荡：Q极高，振荡频率极其稳定。

9.3-9.4 非正弦波产生电路

  • 方波发生器：迟滞比较器+RC充放电回路；输出方波，周期 T ≈ 2RC ln(1+2R2/R1)。
  • 锯齿波发生器：比较器+积分电路，产生锯齿波形。

第9章复习题型与解题思路（非教材原题编号）

9.1 判断电路是否满足正弦波振荡相位条件；RC桥式电路R、C已知求振荡频率f0。

查看解题思路
RC桥式 f0=1/(2πRC)；相位条件总相移0或者360°；Auf>3满足起振幅值条件。

9.2 一阶有源低通滤波，求截止频率fp，写出电压传输函数。

查看解题思路
fp=1/(2πRC)；低频信号通过，高频被衰减。

9.3 方波产生电路，R、C、分压电阻给定，求输出方波周期T。

查看解题思路
T≈2RC ln(1+2R₂/R₁)；改变RC可以调节输出方波频率。

9.4 电容三点式LC振荡电路，L、C参数，求振荡频率f0。

查看解题思路
f0≈1/(2π√(LC))。

第10章 直流稳压电源

10.1 直流稳压电源四大部分

  • 电源变压器：把电网220V交流变换为合适幅值的交流电压u2；
  • 整流电路：二极管整流，交流变单向脉动直流；
  • 滤波电路：电容/电感滤波，减小脉动；
  • 稳压电路：输出稳定直流电压，抑制电网、负载变化带来输出波动。

10.3 单相整流滤波电路

  • 单相半波整流（无滤波）：输出电压平均值 UO(AV) = 0.45U2；二极管反向耐压 URM = √2 U2。
  • 单相桥式整流（无滤波）：UO(AV) = 0.9U2；每个二极管反向耐压 URM = √2 U2。
  • 桥式整流+电容滤波：带负载RL，一般RC≥(3~5)T/2，输出UO(AV)≈1.2U2；空载输出≈√2 U2。

10.4-10.5 稳压电路

  • 稳压二极管稳压电路：限流电阻必不可少；适合小电流简单稳压。
  • 串联反馈式稳压电路：调整管、基准电压、比较放大、采样电阻；通过采样输出电压，反馈控制调整管管压降，稳定输出电压。

第10章复习题型与解题思路（非教材原题编号）

10.1 单相桥式整流电路，U2已知，无滤波，求UO(AV)，每个二极管平均电流ID，二极管反向耐压URM。

查看解题思路
UO(AV)=0.9U₂；每个二极管电流ID=IO(AV)/2；URM=√2 U₂。

10.2 桥式整流+电容滤波，U2；分空载、带负载两种情况求输出电压平均值。

查看解题思路
空载UO=√2U₂；带满足RC≥(3-5)T/2，UO(AV)≈1.2U₂。

10.3 稳压管稳压电路，UI、UZ，负载RL，求限流电阻R取值范围。

查看解题思路
IZ必须在IZmin~IZmax之间；IR=(UI-UZ)/R；IZ=IR-IL，解R上下限。

10.4 串联型稳压电源，基准UREF，采样分压电阻R1,R2，求输出电压可调范围。

查看解题思路
UO=UREF(1+R下/R上)；电位器滑动改变分压，得到最大最小输出。

10.5 三端稳压器7812应用电路，说明输出电压；输入电压最低要求。

查看解题思路
7812输出固定+12V；输入至少比输出大2~3V压差，才能正常稳压。
