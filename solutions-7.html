第7章逐题解析：反馈判断与深度负反馈

以下“＋、－”表示相对静态值的瞬时增量，不是直流电位正负。直流分析令电容开路；题设中频交流分析令电容短路、直流电源交流接地。判断负反馈要看反馈是否削弱净输入，不能只看输出与输入同相还是反相。

7.1 电容改变反馈通路：两图均有直流负反馈、无交流反馈

原题与图7.1：教材170页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

图(a)

直流时C开路，输出经R₂、R₁分压返回反相端：uf=u−=R₁uo/(R₁+R₂)。假设输出电位升高，反相端电位随之升高，净输入u+−u−减小，抑制原来的输出升高，所以是直流负反馈。

交流时C把反相端直接接到交流地，u−=0；输出虽经R₂流过电流，但不能在反相端产生反馈电压。因此没有交流反馈。此时R₂相当于交流输出负载的一部分，不能仅凭“输出还连着电阻”就判定存在反馈。

图(b)

直流时C开路，输出通过R₃、R₂串联返回反相输入节点。若输入为正增量，运放输出趋向负增量，返回反相端的电流削弱原来的输入电流，因此是直流负反馈。在线性理想模型下直流闭环增益为−(R₂+R₃)/R₁。

交流时C把R₂、R₃的中点短接到地：R₃变成输出对地电阻，R₂变成反相端对地电阻，输出变化被交流地隔断，故没有交流反馈。没有交流负反馈时，不能再用“虚短”求交流线性增益。

7.2 两种运放电路的反馈信号与瞬时极性

原题与图7.2：教材170页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

图(a)

交流时输入耦合电容短路。标记同相端u+为“＋”→输出uo为“＋”→经R₃、R₁分压的反相端为“＋”。反馈使净输入ud=ui−uf变小，是负反馈，反馈信号是电压：

uf=R₁uo/(R₁+R₃)，Auf≈1+R₃/R₁。

R₂提供同相端直流通路；它不是从输出返回的反馈元件。

图(b)

交流时电容短接R₂，输出直接接反相端。ui“＋”→uo“＋”→u−“＋”，仍削弱净输入，故为负反馈。此时uf=uo，反馈系数为1，理想交流增益约为1，是电压跟随关系。直流时C开路，仍有R₂、R₁构成的负反馈，直流增益约1+R₂/R₁。

7.3 区分局部反馈与跨两级的反馈

题干：170页 · 图7.3：171页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

图(a)：级间电流并联负反馈

A₂的R₃从输出接回反相端，构成A₂本级的电压并联负反馈。跨两级的通路则通过负载RL返回A₁同相输入节点。设该节点为x，A₁输出为v₁，A₂输出为v₂，题图负载电流io方向自上向下。

瞬时极性沿前向通路为：x“＋”→v₁“＋”→v₂“－”。v₂降低会增大从x经RL向下流出的电流，把输入节点电流分流走，减小净输入，所以是负反馈。标反馈电流if沿x→RL→A₂输出，则if=io，输入节点满足i净=ii−if。

反馈采样的是负载电流，输入端以电流相减，故为电流并联负反馈。作检验：深反馈时x≈0，io≈ui/R₁；输出电流主要由输入和R₁决定，而不是由RL决定。

图(b)：级间电压串联负反馈

A₂通过R₄构成本级反相负反馈。跨级反馈由输出经R₂、R₁分压返回A₁的同相端，uf=R₁uo/(R₁+R₂)。瞬时极性为：输入ui“＋”（接A₁负端）→A₁输出“－”→A₂输出“＋”→A₁正端反馈电压“＋”。反馈抵消了输入造成的负向差模电压，是电压串联负反馈。深反馈时uf≈ui，总增益约1+R₂/R₁。

7.4 PNP复合放大与负载电流取样

题干：170页 · 图7.4：171页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

图(a)：电压串联负反馈

运放输出驱动PNP管基极，输出取PNP集电极。标ui“＋”→运放输出/管基极“－”→PNP集电极uo“＋”→运放同相端“＋”。同相端的返回增量抵消输入在反相端造成的差值，故为负反馈。

xf=uf=R₁uo/(R₁+R₂)。

输出电压分压取样，输入以两端电压作差，故是级间电压串联负反馈。R₃处在PNP发射极通路，还起到局部稳定电流的作用；题目要求的跨级组态由R₂、R₁通路判断。

图(b)：电流串联负反馈

R₂和R₅分别构成两只运放本级的反相负反馈。跨级反馈来自负载RL下端的R₆：负载电流io向下流过R₆，产生uf≈ioR₆，返回A₁同相端；理想运放输入不分流。

瞬时极性为：ui“＋”→A₁输出“－”→A₂输出“＋”→io增加→R₆上端“＋”→A₁同相端“＋”，抵消原来的输入作用。反馈检测输出电流，且以电压形式串联比较，故为级间电流串联负反馈，xf=uf≈ioR₆。这里的uo是RL两端电压，不是A₂输出端相对地的电压，二者相差R₆上的电压。

7.5 分立晶体管中的电流反馈

题干：170页 · 图7.5：171页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

图(a)：电流并联负反馈

T₁为共基输入，输入加在发射极，T₂为射极输出。ui“＋”→T₁集电极/T₂基极“＋”→T₂发射极输出“＋”。T₂电流增大使R₂上的压降增大，因而T₂集电极为“－”。该负增量通过R₁返回输入节点。

把反馈电流if画为输入节点→R₁→T₂集电极，则if=(ve1−vc2)/R₁；vc2降低时，分流增大，净输入电流减小，所以是负反馈。R₂通过T₂集电极电流取得反馈信息，输入端又作电流叠加，故为级间电流并联负反馈，反馈量xf=if。不要因为负载接在发射极、反馈接在集电极，就把这一通路误看成直接输出电压分压。

图(b)：交流级间电流串联负反馈

中频时C₂把R₃、R₇的连接点接到交流地，切断了这一路的交流反馈；C₃旁路T₂射极电阻R₆。仍起作用的跨级通路是T₃发射极→R₄→T₁发射极。

标T₁基极“＋”→T₁集电极/T₂基极“－”→T₂集电极/T₃基极“＋”→T₃集电极输出“－”；同时T₃发射极为“＋”，经R₄使T₁发射极也为“＋”，减小T₁的ube1，所以是负反馈。

在T₁发射极标反馈电压uf，参考方向为发射极对地。它由T₃发射极电流在R₉及反馈网络中引起，并不是直接取T₃集电极输出电压的分压，故为电流串联负反馈。若暂忽略T₁射极电流对反馈网络的加载，则uf≈[R₂/(R₂+R₄)]ve3；实际分析保留加载。

补充直流辨析：C₂开路后，R₇、R₃又构成从T₃集电极返回T₁基极的直流负反馈通路；这与题目通常考查的中频R₄通路应分开。T₁的R₂、T₂的R₆、T₃的R₉还分别参与局部直流稳定。

7.6 反馈组态、输入输出电阻及闭环增益

图7.6：171页 · 四个小问：172页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

看图分析

上管T是射极跟随输出级，输出取在发射极；R2与R1对输出电压取样，分压点接反相端。运放与T在线性区、环路增益足够大时，uᵢ≈uf=uₒ/11，因此增益约11。运放供电引脚省略，R3不能误当反馈分压下臂。

看图分析

为避免原图中A2朝左造成误读，这里把理想电压跟随器等效成对地电压源vf=uₒ；右上端只表示它从uₒ取样，输入不取电流。A1的反相端通过R3接vf，形成电压并联负反馈；虚地下列KCL即得uₒ/uᵢ≈−R3/R1。图中的等效源受uₒ控制，不是独立电源。

图(a)

  1. 极性与反馈信号：ui“＋”→运放输出/T基极“＋”→射极uo“＋”→反相端uf“＋”，因此ud=ui−uf减小。uf=R₁uo/(R₁+R₂)。
  2. 组态：输出电压取样，输入电压串联比较，是电压串联负反馈；射极输出管包含在环路内。
  3. 电阻：串联混合使输入电阻增大，电压取样使输出电阻减小。R₃为输出负载，不是反馈分压的下臂。
  4. 深反馈计算：ui≈uf，故Auf≈(R₁+R₂)/R₁=(1k+10k)/1k=11，同相。此结果要求运放与T均未进入输出限幅，且反馈环路有足够增益。

图(b)

先认清朝左画的A₂：其输出在左侧，反相端与自身输出相连，同相端接uo，所以它是电压跟随器，左侧输出vf≈uo。

  1. 极性与反馈量：ui“＋”→A₁输出uo“－”→A₂输出vf“－”。反馈通过R₃从A₁反相输入节点吸走电流，抵消原输入；反馈信号为电流。若把从A₂输出流向求和节点定义为正，则if,in=(vf−v−1)/R₃，为负增量。
  2. 组态：电压并联负反馈。A₂自身另有局部电压串联负反馈。
  3. 电阻：输入端并联混合使混合节点看入电阻减小，计入R₁后信号源所见输入电阻近似R₁；输出电阻减小。
  4. 深反馈计算：A₁正端经R₂接地且不取电流，故v+=0、v−≈0。列输入节点KCL：ui/R₁+vf/R₃≈0，再用vf≈uo，得到Auf≈−R₃/R₁。题未给R₁、R₃数值，应保留此表达式。
7.7 共射并联反馈与差分输入串联反馈

原题与图7.7：172页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

看图分析

图中电容按中频短路，直流电源只对交流等效接地。Rf连接集电极输出与基极求和节点，箭头if取基极流向集电极为正；输入升高引起uo降低，会使分流if增大。深反馈时ui≈0，得到的是uo/us而不是uo/ui。

图(a)

  1. 极性和反馈量：基极输入“＋”→共射集电极输出“－”。Rf把输出变化返回基极。取反馈电流从基极节点经Rf流向集电极为正：if=(ui−uo)/Rf；输出降低使该分流增大，净基极电流减小，故为负反馈。
  2. 组态：电压并联负反馈。直流时反馈电阻仍相连，也能稳定静态工作点；此处计算中频交流。
  3. 电阻：反馈放大器输入电阻减小，输出电阻减小。信号源内阻Rs不属于反馈放大器自身的输入电阻。
  4. 深反馈计算：求和节点交流电压ui≈0，基极净输入电流可忽略，故(us−ui)/Rs≈(ui−uo)/Rf。于是Ausf=uo/us≈−Rf/Rs。注意题图把ui标在Rs之后；这个比值不是uo/ui。

图(b)

  1. 极性和反馈量：T₁基极“＋”→T₁集电极/T₃基极“－”→PNP管T₃集电极输出“＋”→T₂基极反馈“＋”。T₂基极升高会减小T₁、T₂的差模输入，形成负反馈。xf=uf为T₂基极对交流地电压。
  2. 组态：电压串联负反馈。±12V电源在交流等效中均接地，Rb2是反馈分压下臂。
  3. 电阻：输入电阻增大，输出电阻减小。
  4. 深反馈计算：忽略两输入基极电流造成的电阻压降，T₁基极电压≈ui，T₂基极uf≈uoRb2/(Rb2+Rf)。差模净输入近似零，因此Auf≈1+Rf/Rb2，同相。若基极电流与Rb1压降不可忽略，应回到小信号模型，不能把该近似当精确恒等式。
7.8 电压并联与电流并联：输出电阻变化相反

原题与图7.8：172页

展开原题与电路图

以下为原题所在整页，包含同页其他题；在图框内滚动查看，点击可放大。

看图分析

这是原电路反馈支路的局部交流等效图，主放大链T1→T2及集电极负载暂不画出。深反馈使T1基极增量近似0，输入电流主要经Rf流到T2射极；该节点电流同时通过Re2和Rf分流。忽略T2基极电流、取输出向外提供为正，才得到Aif≈1+Rf/Re2；不要漏掉Rf分支的电流。

图(a)

  1. 极性和反馈量：T₁基极“＋”→T₁集电极/T₂基极“－”→T₂射极输出“－”。R₄使从输入节点流向输出的分流电流增加，削弱净基极输入。标if方向为T₁基极→R₄→uo，if=(vb1−uo)/R₄。
  2. 组态：电压并联负反馈；R₃同时引入T₁局部射极负反馈。
  3. 电阻：混合节点看入电阻减小，计入串联输入电阻R₁后整体输入电阻约R₁；输出电阻减小。
  4. 深反馈计算：令净输入很小，vb1≈0、基极电流可忽略。输入节点KCL为ui/R₁≈−uo/R₄，故Auf≈−R₄/R₁。R₃影响达到深反馈的开环增益和适用范围，不能据此说R₃“没有作用”。

图(b)

  1. 极性和反馈量：T₁基极“＋”→T₁集电极/T₂基极“－”→T₂集电极uo“＋”；T₂发射极则为“－”。这个负增量经Rf返回T₁基极，使净输入电流减小。标反馈电流if从T₁基极流向T₂发射极，if=(vb1−ve2)/Rf。
  2. 组态：在T₂射极电阻处检测输出级电流，以电流返回输入求和节点，是电流并联负反馈，不是电压并联负反馈。
  3. 电阻：输入电阻减小，输出电阻增大；“电流反馈使输出更接近恒流源”可帮助记忆。
  4. 深反馈计算：令vb1≈0，输入电流ii≈if，则ve2≈−iiRf。T₂射极电流增量为ie2≈ve2/Re2+ve2/Rf=−ii(1+Rf/Re2)。忽略基极电流，取输出向外提供的电流io≈−ic2≈−ie2，得到Aif=io/ii≈1+Rf/Re2。

若把输出电流改定义为向下流入T₂集电极，增益应带负号；必须先说明参考方向。若还要求有源内阻Rs时的电压增益，令R′C2=RC2∥RL（空载时R′C2=RC2），则uo/us≈(1+Rf/Re2)R′C2/Rs。这是把电流增益进一步换算为电压增益，不能把二者直接混用。
